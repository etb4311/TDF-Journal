## Lecture Notes

- Computer Vision
- Taking inputs from the world and asking a computer to interface
  - NON-OBVIOUS NOT VISUAL INPUTS CAN BE MORE IMPACTFUL
- visual data can be interpreted in a variety of ways, even with the same input
    - E.G. Marks ->Features -> Relationships -> Interpretation
- world -> camera -> pixels -> patterns -> meaning
- How are images captured by computers?
  1. Input image
  2. patches -> image is divided into small regions
  3. visual tokens -> each patch becomes a token-like unit the model can process
  4. visual embeddings -> each visual token is converted into a numerical vector capturing visual info
  5. text embeddings -> back end model recognizes visual embeddings as objects like 'sky' 'mountains' 'trees'
- Image Models: Architecture (processing images to create or reconstruct visual representations) vs. Tasks (tasks used to share visual representation to predict different outputs)

- Future is 2D images to 3D operations -> gaussian splatting

# COMPUTER VISION TOOLS

- classifier tools: new category label for each training image
- detection tools: a class and bounding box for each labeled object
- signifier tools: a semantic class for each label trained pixel
- landmark tools: a named anatomical landmark indicating positions and visibility in training images
