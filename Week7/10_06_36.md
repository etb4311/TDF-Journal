### Machine Learning Methods in Computer Vision: Virtual Environments

**Virtual Environment:** a bounded digital context in which specific tools, rules, data, or interactions can operate.
  - Software VE manages computation.
      - Controls software dependencies
      - Lets code and models run reliably
      - Ex: python venc/Conda
  - Simulated VE manages a world.
      - Represents a digital world
      - Lets agents, objects, and sensors interact
      - Ex: unity/unreal
   
  INTEGRATION turns these tools into a working system (CLI's, skills, etc.)

  Model Output:
  1. Capture 
  2. Estimate Pose
  3. Map Keypoints
  4. Drive Rig
